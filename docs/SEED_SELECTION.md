## Proposed text

Seeds are set before the model runs, so the graphs cannot be chosen to fit the
results. A seed qualifies if:

- the goal stays reachable under every scenario;
- the control scenarios leave the best route untouched, while the
  route-changing scenarios move it;
- the best route is unique before and after the edit, since under a tie a
  correct re-plan is indistinguishable from a lucky choice.

Criterion two is applied per condition rather than per seed, for reasons given
below.

**Stochastic mode.** Of seeds 1 to 30, seven (2, 3, 6, 14, 15, 24, 27) have no
on-route link whose removal keeps the goal reachable in both modes, so no
route-changing scenario can be built on them. The remaining **23 seeds** (1, 4,
5, 7, 8, 9, 10, 11, 12, 13, 16, 17, 18, 19, 20, 21, 22, 23, 25, 26, 28, 29, 30)
satisfy reachability and uniqueness on every condition, and are the run set.

`no_change` and `irrelevant` additionally build on the seven excluded seeds,
because neither requires a breakable on-route target. We do not use that
surplus. Matched mode exists so that a seed gives the same graph, start, goal
and target link across conditions; comparing `no_change` on 30 graphs against
`silent_break` on 23 would confound the intervention with the seven extra
graphs.

**Degradation and the restraint cases.** On 14 of the 23 seeds, halving the
success probability of the target link makes an alternative route cheaper and
the optimal route moves. On the remaining **9 seeds it does not**: the link
gets worse, but no detour is cheaper, so the best plan is unchanged.

These nine are kept rather than discarded, and labelled `restraint`. The edit
is real and detectable, so detection, localization and preservation remain
fully informative. Adaptation does not: we verified that replaying the
pre-change route in the post-change world scores **regret 0.0 on all nine**,
because the old route is genuinely still optimal. Adaptation there cannot
distinguish a model that correctly concluded no re-plan was needed from one
that ignored the change entirely, so on restraint instances it is reported as a
restraint check and not as a re-planning score.

The combination is what makes them useful: a model that detects the change,
names the link, marks preservation correctly, **and** keeps its route has
demonstrated something no other condition in the battery tests, which is
knowing without needlessly acting.

**Deterministic mode.** Integer hop costs create equal-cost paths, so the
uniqueness criterion almost never holds: only **3 of 30 seeds** (8, 13, 25)
qualify at full strictness, and every one of the 106 excluded cells fails on
uniqueness alone, never on reachability or on a control moving the route.

Three seeds is too few to report. We therefore relax uniqueness in
deterministic mode, which raises the run set to the same 23 seeds, and flag
deterministic adaptation as tie-degraded. The reasoning matches the restraint
case: a tie makes the *routing* probe ambiguous, since a correct re-plan and a
lucky choice are indistinguishable, while detection, localization and
preservation are unaffected.

**Why this differs from the earlier figure.** An earlier draft reported that
only seeds 13 and 25 passed all three criteria in stochastic mode, and that the
runs used seeds 1, 4 and 10. Both statements describe the code before v2.2.
Until commit `651f8d7`, `degradation` drew its own target link instead of
sharing the target with `silent_break` and `hard_removal`, so a seed had to
satisfy eligibility for two independent links at once. With degradation
sharing the target, eligibility rises from 2 to 23. Seed 13 is no longer among
the seeds where degradation moves the route, and seed 4 was never stochastically
eligible under the original criterion; it appears only in the deterministic
list with uniqueness relaxed.

## What changed in the numbers, and why it is not a result

This raises n per cell from 1 to 23. It does not make any existing finding
stronger, because no model has been run on the new seed set yet. The
eligibility work fixes a stale criterion; the evidence still has to be
collected.
